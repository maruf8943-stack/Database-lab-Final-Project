E Commerce Web App Database Lab Final Project

This is a simple e commerce web application built using Flask and MySQL for a Database Lab final project.

Features
User registration and login with hashed passwords
Product browsing and shopping cart
Checkout and payment processing
Admin dashboard to manage products add edit delete
Admin can view customers orders and revenue

Technology Used
Backend Python and Flask
Database MySQL using PyMySQL
Frontend HTML CSS JavaScript
Authentication Werkzeug bcrypt

Project Structure
app.py – main Flask application
requirements.txt – python dependencies
static – CSS JavaScript and images
templates – HTML files
first connect mysql with app.py,
then i deploy sql in railway.com
